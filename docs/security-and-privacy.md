# 安全与隐私

会话、记忆、任务、设置和审计记录默认保存在用户的 E-Assisant 数据目录。用户应当能够通过产品界面查看和管理这些数据。

只有明确需要联网研究、网页读取、媒体生成、消息发送或外部服务时，相关数据才会发往对应服务。搜索本地文件不会自动把路径或文件名发送到互联网。

API Key 等凭据属于敏感配置：界面只应显示掩码，日志和模型上下文不得输出原文，长期记忆不得保存凭据。

每个工具声明风险等级。写入、删除、发送和系统变更等操作必须遵守权限确认；关键操作完成后由核验器检查真实结果并生成审计收据。

在授权发送邮件、上传文件、发布网页或执行系统变更前，应确认目标、内容和影响范围。定期备份 `%APPDATA%\e-assisant` 可以降低本地数据损坏风险。
