# E-Assisant 用户指南

## 开始使用

启动 E-Assisant 后，启动动画会自动转入主页。主页左上角显示产品名称和正式 Logo；中央智能核心展示当前运行状态，左侧入口用于进入对话、记忆、任务、能力、媒体和设置页面。

## 联网搜索与网页学习

可以直接输入：

- `搜索一下今天的人工智能新闻`
- `先上网了解低空经济，再给我一份视频脚本`
- `总结这个链接：https://example.com/article`

E-Assisant 会先搜索，再读取相关网页正文，并在回答中保留实际使用的来源链接。对于登录页、JavaScript 动态页面或视频页面，如果没有取得正文，会明确说明限制。

## 本地任务

可以要求 E-Assisant 查看系统状态、打开应用、整理文件、创建文档或执行已注册工具。涉及写入、删除、发送或高风险系统操作时，界面会显示权限确认。

## 记忆与自动化

只有明确表达为长期偏好的内容才应写入记忆，例如“以后回答先给结论”。任务中心支持一次性提醒、周期计划和系统条件监控，例如“每天上午九点生成系统简报”或“CPU 连续过高时提醒我”。

## 媒体功能

图片和视频生成需要在设置中配置对应服务的 Base URL、API Key 和模型名称。本地音视频裁剪、转码和信息读取需要 FFmpeg。当前不支持直接理解在线视频链接中的完整画面、音频或字幕。

## 故障处理

- 搜索无结果：更换关键词，或直接粘贴目标网页链接。
- 网页正文为空：页面可能需要登录或执行 JavaScript，可改用浏览器操作。
- 生成媒体失败：检查服务地址、模型名称、额度和 API Key。
- 本地工具不可用：进入“能力”或“设置”页面查看依赖状态。
- 应用无法启动：查看 `%LOCALAPPDATA%\E-Assisant\deploy.log`。
